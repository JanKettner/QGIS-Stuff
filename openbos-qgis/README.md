# OpenBOS QGIS

QGIS-Erweiterung für taktische BOS-Zeichen mit separatem Elektro-Symbolbrowser.

Aktueller Stand: v7.0.1.

Die SVG-Bibliothek umfasst THW-Einheiten, Fahrzeuge, Ausstattung, Elektroversorgung, Verteiler und Anschlüsse, Beleuchtung, Schutz und Sicherheit, Messung und Überwachung, Einsatzinfrastruktur, Kommunikation und IT, Betriebszustände, Topografie sowie BOS-Organisationen.

> Hinweis: Der vollständige Plugin-Bestand einschließlich der großen SVG-Bibliothek wird in diesem Unterverzeichnis geführt.
