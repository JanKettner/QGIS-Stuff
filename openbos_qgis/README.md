# OpenBOS 7.0.0

Neu strukturierte QGIS-Erweiterung für taktische BOS-Zeichen.

## Installation

1. Eine ältere OpenBOS-Version im QGIS-Erweiterungsmanager deinstallieren.
2. Den verbliebenen Ordner `openbos_qgis` im Profilordner löschen.
3. QGIS neu starten.
4. `openbos_qgis_v7.0.0.zip` über **Erweiterungen → Erweiterungen verwalten und installieren → Aus ZIP installieren** installieren.

## Zuordnung

Nur Symbole unter `svg/THW Elektroversorgung/` erscheinen im Elektro-Browser. Alle übrigen Kategorien bleiben im BOS-Browser.
