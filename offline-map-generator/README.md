# Offline Map Generator

Separate QGIS-Erweiterung zum automatischen Herunterladen von Geofabrik-OSM-Extraktdateien und Erzeugen offline nutzbarer QGIS-Karten.

Aktueller Stand: v0.2.0.

Funktionen: Geofabrik-Katalog, Kartenausschnitt, PBF-Download, Zuschnitt mit osmium, GeoPackage-Erzeugung mit ogr2ogr und QGIS-Projekterzeugung.
